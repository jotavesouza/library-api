# Library API

API REST para gerenciamento de uma biblioteca, desenvolvida com Java 17 e Spring Boot.

O objetivo deste projeto é construir uma aplicação backend para controle de livros, autores e empréstimos, aplicando boas práticas de desenvolvimento com o ecossistema Spring.

Durante o desenvolvimento, o projeto será evoluído gradualmente, passando por conceitos como criação de APIs REST, persistência de dados, validações, segurança, documentação e testes automatizados.

## Objetivo

Criar uma solução para gerenciamento de uma biblioteca, permitindo o controle de informações como:

- Cadastro e gerenciamento de livros;
- Cadastro de autores;
- Controle de empréstimos;
- Consultas e filtros;
- Autenticação e autorização de usuários.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Flyway
- Spring Validation
- Spring Security
- Lombok
- OpenAPI / Swagger
